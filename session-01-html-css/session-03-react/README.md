# Session 03 - REACT
This session for training about REACT for front-end developemnt with typescript


## 1 - Tech Stack
React: [https://react.dev](https://react.dev)

## 2 - Vite
Vite is the build tools for web

Vite: [https://vite.dev](https://vite.dev)

**Install Vite**
* use ***npm*** 

```shell
$ npm create vite@latest
```

* use ***yarn*** 

```shell
# install yarn
$ npm install --global yarn

# use yarn to create vite
$ yarn create vite
```

## 3 - Create React application with Vite and TypeScript 

* use ***npm*** 

```shell
$ npm create vite@latest <projectname> -- --template react-ts
```

* use ***yarn*** 

```shell
$ yarn create vite <projectname> -- --template react-ts
```

## 4 - Run React application

### 4.1 - Install node module

* use ***npm*** 
```shell
$ npm install
```

* use ***yarn*** 
```shell
$ yarn install
```

### 4.2 - Build and Run React application

* use ***npm*** 
```shell
$ npm run dev
```

* use ***yarn*** 
```shell
$ yarn run dev
```
